Base URL locale recommandée :
http://localhost:8017

Exemples de variables :

Linux/macOS
export BASE_URL="http://localhost:8017"
export TOKEN="ton_token"
alias apicurl='curl -sS -H "Authorization: Bearer '"$TOKEN"'"'

Windows PowerShell
$env:BASE_URL = "http://localhost:8017"
$env:TOKEN = "ton_token"

1) Health
apicurl "$BASE_URL/health"

2) Recherche série One Piece
apicurl --get "$BASE_URL/search" \
  --data-urlencode "q=one piece" \
  --data-urlencode "kind=series" \
  --data-urlencode "mode=best" \
  --data-urlencode "limit=10"

Attendu :
- `data[0].title = One Piece`
- `data[0].title_vo` si disponible
- `data[0].vf.volumes = 112`
- `data[0].vo.volumes = 114`

3) Resolve série One Piece
apicurl --get "$BASE_URL/search/resolve" \
  --data-urlencode "q=one piece" \
  --data-urlencode "kind=series" \
  --data-urlencode "limit=10"

Attendu :
- `data.best.slug = One-piece-Edition-originale`
- `data.best.vf.volumes = 112`
- `data.best.vo.volumes = 114`

4) Fiche série One Piece
apicurl "$BASE_URL/series/One-piece-Edition-originale"

Attendu :
- `data.title = One Piece`
- `data.vf.volumes = 112`
- `data.vf.status = En cours`
- `data.vo.volumes = 114`
- `data.vo.status = En cours`

5) Recherche volume One Piece tome 91
apicurl --get "$BASE_URL/search/resolve" \
  --data-urlencode "q=one piece tome 91" \
  --data-urlencode "kind=volume" \
  --data-urlencode "limit=10"

Attendu :
- `data.best.series_slug = One-Piece`
- `data.best.volume_slug = vol-91`

6) Fiche volume 91
apicurl "$BASE_URL/volume/One-Piece/vol-91"

Attendu :
- `data.number = 91`
- `data.vf.volumes = 112`
- `data.vo.volumes = 114`

7) Planning VF Glénat / avril 2026 / One Piece
apicurl --get "$BASE_URL/planning" \
  --data-urlencode "section=manga-vf" \
  --data-urlencode "year=2026" \
  --data-urlencode "month=4" \
  --data-urlencode "publisher=Glénat" \
  --data-urlencode "q=one piece" \
  --data-urlencode "sort=date_desc" \
  --data-urlencode "limit=10"

Si les compteurs restent `null` alors que Manga-News les affiche, vérifier :
- que la réponse ne vient pas d'un vieux cache applicatif ;
- que l'application tourne bien avec le build courant ;
- que la page source contient toujours un bloc `#numberblock`.
