# Examples

Ce dossier contient des payloads JSON d'exemple validés contre les modèles Pydantic du projet.

Fichiers clés :
- `health.json`
- `search_response_dogs_volume.json`
- `resolve_response_one_piece.json`
- `series_one_piece.json`
- `volume_one_piece_91.json`
- `planning_example.json`
- `news_global_one_piece_sample.json`

Les exemples de recherche et de fiches détaillées incluent aussi les compteurs `vf` / `vo`. Sur les volumes, ces compteurs viennent de la série parente.
