# JSON examples

These files are fixed payload examples meant for developers, integrators, or another AI agent.
They are also validated in CI against the Pydantic response models to keep the docs aligned with the code.

Available examples:
- `health.json`
- `search_response_one_piece.json`
- `resolve_response_one_piece.json`
- `series_one_piece.json`
- `volume_one_piece_91.json`
- `series_related_one_piece.json`
- `series_editions_one_piece.json`
- `planning_example.json`
- `error_upstream_parse.json`
